# Korean Law Portal (교사용 대한민국 법령 AI 가이드)

선생님과 학생이 학교 현장에서 마주하는 복잡한 법령과 행정규칙을 AI 어시스턴트(Claude, Cursor 등)로 쉽게 확인하도록 안내하는 웹 포털입니다.

---

## 1. 이 사이트로 할 수 있는 일 3가지

1. **학교 필수 법령 및 개정 이력 즉시 확인**
   - 학교폭력예방법, 교원지위법, 개인정보 보호법, 저작권법 제25조 등 학교 업무에서 가장 자주 찾는 법률과 시행령을 즉시 살펴볼 수 있습니다.
2. **AI 어시스턴트에 법률 MCP 원클릭 연동**
   - 별도 코딩 없이 법제처 무료 API 키(OC) 하나로 Claude 웹 커넥터, Cursor, Claude Desktop 등에 대한민국 법령 검색 도구를 연결합니다.
3. **법률, 시행령, 별지 서식까지 한 번에 이어지는 입체 탐색**
   - 법 조문뿐만 아니라 시행규칙, 과태료 처분 기준표(별표), 행정심판 재결례까지 하나의 질문 흐름으로 조사할 수 있습니다.

---

## 2. 학교 업무에서 자주 찾는 대표 법령 4선

| 법령명 | 관련 주요 조항 | 학교 현장 검토 내용 |
| :--- | :--- | :--- |
| **학교폭력예방법** | 제13조의2, 제17조, 시행령 제19조 | 학교장 자체해결 4가지 요건, 전담기구 심의 절차, 가해학생 1~9호 조치 기준 |
| **개인정보 보호법** | 제15조, 제22조, 제25조 | 학생 및 학부모 개인정보 수집 동의, 교내 CCTV 설치 목적 및 열람 청구 절차 |
| **저작권법 (제25조)** | 제25조 제2항 및 제3항, 제28조 | 수업 및 수업지원 목적 저작물 인용 범위, 온라인 원격수업 시 복제방지 조치 |
| **교원지위법** | 제19조, 제20조, 시행령 제15조 | 교육활동 침해 행위 유형, 피해 교원 특별휴가 및 관할청 긴급 보호조치 |

## 3. 내 AI 어시스턴트에 연동하는 방법

### 1단계: 법제처 Open API 무료 인증키 발급
1. [국가법령정보공동활용 웹사이트](https://open.law.go.kr/LSO/openApi/guideList.do)에 접속해 회원가입합니다.
2. "Open API 사용 신청" 메뉴에서 간단한 신청서를 제출합니다.
3. 발급받은 영문 인증키(OC)를 복사합니다.

### 2단계: Claude 웹(Pro) 커스텀 커넥터 등록
1. Claude 웹 우측 하단 프로필 > 설정(Settings) > 커넥터(Connectors) > **커스텀 커넥터 추가**를 클릭합니다.
2. 아래 주소의 `YOUR_KEY` 자리에 발급받은 본인 인증키를 넣어 등록합니다:
   ```text
   https://korean-law-mcp.fly.dev/mcp?oc=YOUR_KEY
   ```
3. 도구 권한을 **항상 허용(Always allow)**으로 설정하면 질문마다 번거로운 확인 없이 바로 작동합니다.

### 3단계: 데스크톱 개발 도구(Cursor, Windsurf 등) 연동
설정 파일(`mcp.json` 또는 `claude_desktop_config.json`)에 다음 내용을 추가합니다:
```json
{
  "mcpServers": {
    "korean-law": {
      "url": "https://korean-law-mcp.fly.dev/mcp?oc=YOUR_KEY"
    }
  }
}
```
