Korean Law MCP 상세 가이드

대한민국 법령정보센터(law.go.kr)의 방대한 API 생태계를 모델 컨텍스트 프로토콜(MCP)의 형태로 사용할 수 있도록 만든 연결 도구입니다. 41개 이상의 Open API를 최적화하여 Claude, Cursor, Windsurf와 같은 AI 어시스턴트가 단 15개의 시맨틱 도구로 조작할 수 있게 설계되었습니다.

주의: 모든 도구 호출에는 법제처에서 발급받은 무료 인증키(OC)가 필요합니다.

V3 시스템 아키텍처 개요

과거 V2 버전에서는 하나의 API당 하나의 커스텀 도구를 매핑하여(총 89개) AI 프롬프트의 컨텍스트를 과다하게 소모했습니다. 이를 획기적으로 개선한 V3에서는 Dispatch Table 방식을 사용하여 15개 도구로 통합했습니다.

  • 17개 결정례 도메인(판례, 조세심판 등)을 단일 파라미터 domain으로 라우팅.
  • 7가지 상황별 AI 리서치 시나리오(관세, 벌칙 판단, 위임입법 검증 등) 자동 파생.
  • AI 초기 토큰 소모량 110KB에서 약 20KB로 압축 (-82%).

핵심 체인 도구 (Chain Tools)

단순한 데이터 조회가 아니라, AI의 복잡한 쿼리를 처리하기 위해 여러 API를 백그라운드에서 순차/병렬적으로 호출하는 지능형 도구들입니다.

Tool Name 기능 설명 (Description) 지원 시나리오 속성
chain_full_research 주제에 관한 법령부터 판례, 해석례까지 망라하여 종합 분석합니다. customs (관세) 등
chain_law_system 법제 구조도 조회(상/하위법, 위임입법 구조 추적). 미제정 하위법령을 찾습니다. delegation, impact
chain_action_basis 행정처분(과태료, 영업정지, 인허가)의 법적 근거와 경감 사례를 추적합니다. penalty
chain_amendment_track 특정 조문의 과거 개정 이력 기록 및 신구대조표를 테이블 형태로 생성합니다. timeline
chain_ordinance_compare 상위법과 지자체 자치법규(조례)간의 적합도를 비교하고 위헌 소지를 조회합니다. compliance

17 통합 도메인 검색 엔진

search_decisions(domain, query) 하나의 통합 도구 인터페이스로 아래의 17개 이질적인 도메인에 대한 전문 검색이 가능합니다.

  • 사법 및 재결: 판례(대법원), 헌재결정례, 조세심판, 행정심판, 소청심사
  • 정부 유권해석: 법령해석례, 행정규칙(훈령/예규), 권익위, 개인정보위, 공정위, 노동위
  • 기타 규정: 자치법규, 조약, 영문법령, 학칙, 공사공단 등

API 키 인증 (Priority Fallback)

앱 보안 환경이나 클라이언트 도구에 맞게 다양한 방식으로 API 인증키를 설정할 수 있습니다. (높은 번호가 우선 적용)

  1. URL 쿼리 파라미터: 원격 서버 접근 시 ?oc=YOURKEY 부여
  2. HTTP 헤더: API 직접 호출 시 apikey: YOURKEY
  3. 시스템 환경 변수: CLI/로컬 환경에서 LAW_OC=YOURKEY 환경 변수 등록
  4. MCP 도구 파라미터: 클라이언트에서 런타임에 apiKey 매개변수 사용

별표 문서 자동 파싱 엔진 (kordoc 2.2)

대한민국 법령의 핵심인 '별표', '별지 서식'의 한글 문서 포맷들을 완벽하게 AI가 이해할 수 있는 마크다운 스키마로 분해합니다.

  • HWPX, DOCX: kordoc 엔진을 통한 텍스트 및 병합 셀 구조 완전 유지
  • XLSX (엑셀): GFM Markdown 테이블 양식으로 변환
  • HTML 병합 셀 지원: colSpan, rowSpan이 포함된 복잡한 과태료 처분 기준표 등을 HTML 표 형태로 브릿지
