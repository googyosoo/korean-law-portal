01

학교 필수 법령 즉시 확인

학교폭력예방법, 교원지위법, 개인정보 보호법, 저작권법 제25조 등 자주 마주하는 법조문과 핵심 시행령을 클릭 한 번으로 살펴봅니다.

02

내 AI에 법률 MCP 원클릭 연동

Claude 웹, Cursor, Windsurf 등에 무료 법제처 API 키를 연결하여, 질문만 하면 AI가 공인 법령을 스스로 조회하도록 환경을 만듭니다.

03

법률·시행령·서식 원스톱 추적

단순 조문 조회를 넘어 법률에서 위임한 시행규칙, 행정처분 기준표, 별지 서식, 행정심판 재결례까지 하나의 흐름으로 입체 분석합니다.

설치 및 사용 가이드

무료로 제공되는 법제처 Open API 키 하나면 1분 안에 셋업이 완료됩니다.

내 법제처 인증키(OC) 입력기

발급받은 인증키를 아래에 입력하면 설치 코드와 복사 버튼에 즉시 반영됩니다. (외부 서버로 전송되지 않고 브라우저 안에서만 안전하게 동작합니다)

인증키를 입력하지 않으면 기본 예시값으로 표시됩니다.

법제처 Open API 인증키 준비 (필수)

모든 과정에는 법제처 API 키(OC)가 반드시 필요합니다. 교사, 학생, 일반 개발자 누구나 무료로 발급받을 수 있습니다.

1
국가법령정보공동활용 사이트 에 접속하여 회원가입
2
"Open API 사용 신청" 메뉴에서 이용 목적(연구/교육/업무 등)을 간단히 기재하고 신청합니다.
3
신청 완료 즉시 마이페이지에서 발급되는 인증키(OC) 영문자열을 복사하여 위 입력창에 넣어보세요.

Claude.ai 웹에서 즉시 사용 (설치 불필요)

Claude 웹의 커스텀 커넥터 기능을 활용하면 프로그램 설치 없이도 법률 도구를 추가할 수 있습니다. (Claude Pro/Team 구독 필요)

커넥터 URL 추가 
https://korean-law-mcp.fly.dev/mcp?oc=본인인증키
  • Claude 화면 우측 하단 프로필 > 설정(Settings) > 커넥터(Connectors) > 커스텀 커넥터 추가 선택
  • 위의 URL 주소를 그대로 입력하고 저장합니다.
  • 커넥터 상세 설정에서 도구 권한을 '항상 허용(Always allow)'으로 지정하면 매번 확인창 없이 빠르게 실행됩니다.

Cursor, Windsurf, Claude Desktop 등 연동

AI 데스크톱 프로그램의 MCP 서버 설정 파일(`mcp.json` 또는 `claude_desktop_config.json`)에 아래 내용을 추가합니다.

mcp.json 또는 claude_desktop_config.json 
{
  "mcpServers": {
    "korean-law": {
      "url": "https://korean-law-mcp.fly.dev/mcp?oc=본인인증키"
    }
  }
}

설정을 저장한 뒤 앱을 완전히 재실행하면 AI에게 대한민국 법령 도구가 즉시 주입됩니다.

내 컴퓨터 터미널에서 직접 실행하기 (CLI)

Node.js 환경이 설치되어 있다면 터미널 명령어 한 줄로 프롬프트 질의가 가능합니다.

Terminal (Bash / PowerShell / Zsh) 
# 대화형 설치 마법사 실행 (가장 추천)
npx korean-law-mcp setup

# 환경 변수로 인증키 등록 시
export LAW_OC=본인인증키     # Mac / Linux
$env:LAW_OC="본인인증키"  # Windows PowerShell

# 터미널에서 직접 질의 실행
korean-law "학교폭력예방법 제13조의2 요건 알려줘"
